## Tải về

**[⬇ Bản mới nhất cho mọi thiết bị](https://github.com/vtvcab17-max/micron/releases/latest)**: một file zip gồm Windows, macOS, Android, iPad và bản Web. Cách cài cho từng thiết bị nằm trong [HUONG-DAN-CAI-DAT.md](HUONG-DAN-CAI-DAT.md).

Dùng trên web: mở bằng Chrome, Edge hoặc Safari rồi bấm **⬇ Cài ứng dụng**. Trên iPad/iPhone thì chọn *Thêm vào Màn hình chính*.

## Mã nguồn

```
web/       ứng dụng (nguồn chung cho mọi nền tảng)
desktop/   Windows & macOS (Electron)
mobile/    Android & iPad (Capacitor)
.github/   build tự động + "Đóng gói tất cả" → Releases
```

Chỉ cần sửa trong `web/`. Mỗi lần đẩy code lên `main`: Cloudflare tự cập nhật bản web, GitHub Actions tự build lại các bản cài.
